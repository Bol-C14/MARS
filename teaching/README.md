# MARS Trace — 教学与程序理解 IDE

MARS Trace 在原 MARS 4.5 汇编器和执行器上增加现代代码编辑、可回退调试和执行关系叠加。前端使用本地打包的 CodeMirror，不依赖 CDN。机器指令仍由原 MARS `Simulator` 执行。

## 部署入口

- **个人本地**：`sh teaching/scripts/local.sh`；Windows 用 `teaching/scripts/local.ps1`。维护者可通过 `package-local.sh` 生成解压即用的 ZIP。
- **教师公开发布**：`sh teaching/scripts/teacher.sh init mars.example.edu`，再执行 `sh teaching/scripts/teacher.sh up`。Docker Compose 启动 HTTPS、静态前端与多学生网关。

完整步骤、配置、更新与回退见 [DEPLOYMENT.md](docs/DEPLOYMENT.md)。生产网关源码在 `teaching/hosting/`；个人与教师模式使用同一套核心与前端。

## 启动

需要 JDK 17 或更新版本。已在 macOS arm64 / Java 25 验证。

在仓库根目录执行：

```sh
sh teaching/scripts/start.sh
```

打开 **http://127.0.0.1:8765**。服务只监听本机。macOS 可以双击根目录的 `Start-Teaching-IDE.command`：它会启动独立后台进程并打开浏览器，关闭启动终端不会停止服务。命令行 `start.sh` 则以前台方式运行，Ctrl+C 结束服务。

后台启动也可执行 `sh teaching/scripts/start-background.sh`（需要 Python 3）；日志在 `teaching/build/server.log`。已运行时复用现有服务。

指定其他端口：`sh teaching/scripts/start.sh 8766`。首次启动会从源码编译 Java；前端已打包，正常使用无需安装 Node 依赖。当前是本地浏览器工作区，原生安装包属于 M3。

## 开始使用

### 编写与管理自己的工程

首次打开是空白工程，不会自动加载教学演示。源码会自动保存在**当前浏览器**，刷新后恢复文件、目录、当前文件和汇编方式；执行历史需要重新汇编。

顶部是菜单栏：“工程”收纳新建、导入、保存到浏览器、导出到电脑、下载当前文件和恢复；“学习”收纳入门练习、查指令和示例程序；“界面”里切换深浅色、调整代码字号、选择代码字体（JetBrains Mono 默认，另有 Fira Code、Cascadia Code、Source Code Pro、IBM Plex Mono 和系统默认）和恢复默认布局。字体随 IDE 一起发布在 `web/fonts/`（OFL 许可，只含拉丁字符，中文注释用系统字体），不依赖外部字体服务；连字已关闭，`->` 等不会合成一个符号。系统默认在 macOS 上是 SF Mono，Windows 上是 Consolas，Linux 上是 DejaVu Sans Mono 等，所以各系统看起来不同。打开一个菜单后，鼠标移到另一个菜单或按 ←／→ 直接切换。菜单右边是工程名和保存状态，最右是命令面板入口。

- **新建工程**：创建不带演示代码的 `main.s`，替换前会确认。
- **导入**：只有一个入口，把文件、文件夹或 ZIP 拖进对话框，或点击选择，IDE 自己判断类型。单个或几个文件直接添加到当前工程，不询问；整个文件夹、ZIP 或 JSON 工程先预览文件和跳过的内容，再选择作为新工程打开（替换当前内容）或添加到当前工程的根目录或某个文件夹。同名文件需要明确确认覆盖，取消会保留原文件。不能选择文件夹的浏览器会提示压缩成 ZIP 再导入。
- **工程文件树**：`＋ 文件` / `＋ 目录` 新建，目录可以展开；每行 `⋯` 可重命名、移动或删除。修改完整相对路径即可移动文件；目录重命名会同时更新所有子文件和入口。
- **汇编方式**（汇编按钮右侧 ▾ 切换，随工程保存）：
  - **自动汇编**（默认）：正在编辑的文件定义了 `main` 就从它开始；没有 `main` 时在它所在的目录里找定义 `main` 的文件作为入口，正在编辑的文件一起加入；都没有 `main` 时就从这个文件的第一条指令开始。然后自动链接程序用到的全局标签（`.globl`）所在的文件，优先同一目录。另有 `main` 的文件是别的程序，不会被链接进来，所以同一工程里的多个练习各自定义 `main` 也不冲突。只有“当前文件没有 `main`、同目录又有多个 `main`”或“同一个标签有多个来源”时才报错，并说明原因。
  - **单文件汇编**：只汇编正在编辑的文件。
  - **手动选择范围**：在文件树中勾选参与的源码并选择入口，只汇编勾选的文件；首次进入时按自动汇编的结果预先勾选。
  - `.include` / `.incbin` 尚未启用。
- **程序与当前文件**：编辑器上方的“程序：…”说明已装入的程序由哪些源码汇编。切到不属于它的源码时，运行、单步和回退暂停使用，提示条写“你在看 X，现在能运行的是 Y”，并给出［汇编 X］或［回到 Y］；切换汇编方式或修改手动范围后提示重新汇编。调试器跟随执行进入同一程序的其他文件不受影响。编辑不属于已装入程序的文件不会让它失效。
- **断点**按“文件:行”保存；文件不在本次汇编范围内时，断点保留并标为“未参与汇编 · 暂不生效”，再次汇编该文件时恢复。
- **错误标记**：汇编后，出错的词画红色波浪线（警告为黄色），行号标红，文件树里的文件名标红，悬停显示错误信息。改动出错的文字后标记消失，下次汇编重新检查。
- **打字时检查**：停止输入约 0.6 秒检查改动的行，能发现拼错的指令和不对的操作数；约 3 秒后检查整个汇编范围，补上标签等跨行错误。程序运行或演示时暂缓，暂停调试时照常检查且不影响调试状态。需要后端提供检查进程，没有时自动关闭，点“汇编”后的标记不受影响。
- **汇编错误**涉及范围时会说明相关文件：例如两个参与的文件都定义了 `main`、用到的标签在没有参与汇编的文件里，或标签忘了用 `.globl` 声明。
- **文件标签的 ×**：只关闭编辑标签，文件仍保留在文件树，可再次打开。
- **保存 / Cmd/Ctrl+S**：立即保存到当前浏览器；这不等于写回电脑里原来的文件，也不会跨设备同步。存储不可用时会明确提醒导出。
- **导出工程**：ZIP 包含原始源码、UTF-8 输入文件、空目录、汇编方式和手动范围（含入口）；JSON 保存完整工程。没有这些信息的旧工程按自动汇编打开。两者均可重新打开。**下载当前文件**可单独下载正在编辑的源码。
- **恢复上次管理操作**：找回替换、重命名、覆盖或删除之前的工程；只保留上一次结构操作前的备份。浏览器无法保存时，备份仍在当前标签页内有效。

输入文件（如 `.txt`）和源码一起显示在文件树中，点击可编辑；程序通过工程内的虚拟路径访问它们，不会访问学生电脑上的文件。导入只接受 UTF-8 文本，每个工程最多 500 个文件、4 MB 文本内容；二进制文件、越界路径、损坏的工程包会被拒绝并保留当前工程。

1. 选择 `4 · 一个数的几种写法`，运行到输入等待，输入 `898`，观察 `0x00000382` 和二进制。
2. 选择 `5 · 完整项目：成绩统计`，在 `text.s` 行号旁点击设置断点；Alt＋点击可添加条件，例如 `$t0 == 0`。
3. 单步时，实线展示刚完成步骤的真实访问；虚线展示下一步预览。专注模式顶部的“主界面连线”可分别控制两层，以及读取、写入和控制流。
4. 悬停指令或寄存器看简短说明（浮窗第一行写着“⌘／Ctrl＋点击查看详细”，也可以点浮窗里的“查看详细”或按 F12），右侧“详细检查”显示完整说明。点击寄存器可查引用、数值表示、最后写入，以及运行到下一次写入。

## 时间语义

`S_n` 是完成第 n 条机器指令之后的状态。PC 指向下一条待执行指令。

- 实线：`S_(n-1) → S_n` 的真实读写和控制转移。
- 虚线：从 `S_n` 出发的下一步预览。
- 起点没有实线；终点没有可执行的下一步。
- 输入 syscall 的预览停在等待输入，即使输入队列已有内容也不提前消费。
- 预览调用同一执行核心，再恢复寄存器、内存变化、延迟分支、堆位置和虚拟 I/O，不包含第二套指令解释器。

## Limitations

- 个人本地入口每个服务只有一个活动调试会话，多个标签页共用它；教师入口为每个浏览器会话提供独立 Java 进程。修改源码后需要重新汇编；文本编辑在下次汇编时使用，旧调试状态保持。
- 接受整数寄存器为主的课程工程；面板显示 GPR、HI、LO。浮点／异常寄存器被纳入回退快照，但尚无专门面板。
- 支持可回放的 syscall 1–17、34–36；时间、随机、音频、GUI 等服务明确阻止执行。文件访问使用会话内虚拟文件，不直接访问主机文件。
- 当前固定 Default 内存配置和禁止自修改代码。`.include` / `.incbin` 尚未启用，请显式导入项目源码文件。
- 条件断点支持 `$register` 与整数的 `== != < <= > >=` 比较；复杂表达式属于后续扩展。命中次数 N 表示在这条指令从 S0 起第 N 次执行前暂停，随回退变化。日志断点命中时按 `{$t0}`（十进制）、`{$t0:x}`（十六进制）写入底部“日志”，不暂停；每次请求最多记录 200 条。
- 调用视图按 `jal` / `jalr` / `jr $ra` 约定跟踪。循环视图按静态向后边识别；复杂非结构化控制流仍应查看实际轨迹。来源查询目前为最后写入记录，不是完整跨步依赖切片。
- 历史上限为 100,000 条机器指令，达到后明确暂停。控制台和单个虚拟输出文件有 1 MB 上限。尚未完成 M3 的长会话内存预算与发布性能验收。
- 当前为三栏工作区：左侧“文件／符号／断点”三个纵向标签，右侧“详细检查／寄存器／内存”三块面板可上下拖动、各自折叠；栏间与底部面板的分隔线可拖动（双击恢复），“界面 ▾ → 恢复默认布局”一次复原。任意停靠布局、完整课程包、原生安装包与跨平台验收属于 M3。

## 配色

每种颜色只表示一件事（第四轮试用后按 VS Code 调整）：黄色 = 即将执行（同 VS Code 调试），灰色 = 刚执行完；青绿 = 读取，深橙 = 写入（寄存器、内存高亮和连线；2026-11-03 由玫红改为深橙，避免和报错联想）；紫色 = 控制流（跳转与分支指令的语法色、控制流连线）；红色 = 断点与错误；蓝色是按钮和选中等界面元素。代码文字沿用 VS Code Light+ / Dark+：指令蓝、寄存器深蓝、数字绿、标签棕、字符串红、注释绿色斜体。深色主题使用对应的亮色。刚完成与预览另有实线／虚线、✓／→ 区分，不只靠颜色。

## 课堂反馈（2026-10-24）实现说明

- **界面布局**：执行工具栏只有汇编 ▾ 带文字；运行是两个图标按钮：完整运行／回到开头、逐步运行／暂停／继续，开始任何一种运行后都变成“回到开头”和“暂停”（2026-11-03）；回退、机器单步、源码单步、跨过、跳出是另一组图标，悬停或键盘聚焦时显示名称和快捷键，触屏上直接显示文字。左侧“文件／符号／断点”纵向标签一次显示一组，记住选择；断点或观察点在隐藏的标签里触发时，标签上出现提示点。右侧三块面板可拖动高度、折叠到标题，各自滚动，布局偏好保存在浏览器。
- **检查与解释**：悬停只给简短释义和本行公式；右侧“详细检查”给出通用规则（`$a ← $b + $c`）→ 本行代入 → 执行前数值 → 计算过程 → 结果（注明是执行后的实际结果还是尚未执行的预览）→ 关联读写。默认“跟随执行”：每次停下，右侧显示刚执行的那一行（还没执行时预览下一行）；打开某个对象（浮窗里的“查看详细”、Cmd/Ctrl＋点击、F12、点寄存器）就固定它，数值随回退、历史回放和循环中的所选执行步更新，执行离开这一行时标出“执行已到第 N 行”，“回到跟随执行”或“取消固定”恢复跟随。数值分“当前执行前数值”（尚未执行）、“执行前数值”和“完成执行后数值”；同一寄存器出现在等号两边时直接说明右边用的是执行前的值。能逐位查看的指令有“在专注模式中逐位查看”按钮。代码已修改或尚未执行时只显示规则。
- **BIN 寄存器**：完整显示 32 位和 `0b` 前缀，保留前导零和补码位模式；寄存器在 BIN 档每个占一行，必要时只在字节边界换行。负数的悬停提示说明“最高位是 1：按有符号数读是 −7（补码）”；寄存器面板标题旁常驻当前档位的前缀图例（如“0d 十进制 · 0x 十六进制”）。
- **中文说明与术语**：没有专门中文说明的指令，悬停和详细检查改用“查指令”中的中文用途与限制，最后才显示 MARS 英文原文。详细检查里的寄存器名可悬停看约定用途；syscall 详细检查附术语；逐位查看里的补码、溢出、进位可悬停看定义。服务 11 的行尾说明写出字符编码（如“编码 50 是字符 '2'”），详细检查可打开字符编码表。
- **syscall 说明**：界面不用“服务号”这个词，直接写“syscall 做什么由 $v0 的值决定”：详细检查标题写“syscall：读取整数”，下面一句“$v0 = 5 选定了“读取整数”（第 10 行 li $v0, 5 放入）”，不管这一行是还没执行到、即将执行还是已执行，来源都这样写；然后是“做什么 → 需要的参数（含当前值和含义，例如 $v0 = 11 时 $a0 = 45 打印字符 `-`，$v0 = 1 时打印 45；字符串参数是地址）→ 发生什么 → 变化”。读取类调用说明 $v0 会被结果覆盖，解释时仍用调用前的值；等待输入时不显示虚构结果；上方找不到设置 $v0 的指令时写明要执行到这一行才知道；不支持的值明确说明。
- **终端提示**：只有真实执行产生输出时控制台闪一次（新的会取代旧的，减少动态效果时改为静态标记；控制台不在前台时其标签出现提示点）；等待输入时自动切到控制台并点亮输入框，不抢键盘焦点。
- **专注模式**：条件分支下方可展开“未走的路径”：本次比较的值和结果，以及另一侧的源码，标明没有执行、不显示数值。“逐位查看”按真实执行步展示移位（每步一位，补 0 或符号位）、加减（逐位进位、补码、溢出与异常）、按位运算，以及乘除的 HI/LO；可暂停、逐步和重放，减少动态效果时列出全部步骤。
- **查指令**：顶部“查指令”、命令面板或快速打开里输入 `?`，可以按名称、拼写片段、中文用途或常见需求（如“加法”“比较大小”“打印字符”“读取整数”“右移”）搜索指令和 syscall 服务；结果说明用途、格式、通用公式、例子、真实指令或伪指令和限制，并列出本工程中用到的位置；只共用一个词的松散匹配收进默认折叠的“其他可能相关”。只用本地资料，不修改代码。
- **入门练习**：顶部“入门练习”在单独的练习工程里，从打印 Hello! 开始，依次读取名字、用断点／详细检查／内存／专注模式看清它、制造并修好一个整数溢出（改成 addiu 只是不报错，不算修好）、读取年龄输出明年的年龄、导出工程。每一步以目标或问题开始，按 IDE 中实际发生的事检查（文件、装入的程序、输出、断点、观察点、详细检查、专注模式），提示逐条给出，参考答案只显示不填入；可收起、跳过、退出后继续，结束时可保留练习工程或回到练习前的工程。卡片显示在专注模式之上，开着专注模式也能操作。

### 专注模式（逐步解释）

主界面只呈现事实：代码、寄存器、内存、断点和轨迹。刚执行过的源码行在行尾淡显写入结果（如 `$t0 = 7`），回放历史时随所选状态变化。

工具栏右侧的状态标签始终说明机器在做什么：尚未汇编（从没汇编过的工程）、运行中（绿色）、停在断点前（红色，写明文件、行号、这一行尚未执行、即将第几次执行）、观察点触发、等待输入、已暂停（刚执行哪一行）、回放历史、已结束（退出码）。点击可跳到对应行。程序结束后不再标出“下一条”，编辑器停在最后执行的那一行；第一个按钮是“回到开头”，重新汇编当前装入的程序并停在第一条指令前，断点保留，需要输入时重新等待输入；F5 则直接从头再运行一遍。执行按钮不可用时，悬停会说明原因（程序已结束、代码已修改、正在查看另一个文件等）。汇编出错时底部切到“问题”，改好并汇编成功后自动回到“控制台”。F5 全速运行，运行时编辑器不跟随；“逐步运行”一步一步执行并跟随，执行进入其他文件时提示“执行进入 文件 · 标签”并闪烁标签页。逐步运行中滚动代码或打开别的文件，会暂时停止跟随，约 4 秒没有操作后自动回来；只要正在执行的行不在视野里（包括暂停时），编辑器右下角就有一个小按钮，点一下回到这一行并继续跟随。暂停会等正在执行的一批完成，期间显示“正在暂停…”。

页脚“专注模式”和“数值显示”带图标、字号略大并加粗，“数值显示”右边的圆形“?”按钮打开说明；PC 显示在编辑器头部“程序”标签左边；页脚右侧“MARS 4.5”打开内核说明（暂不能切换内核）。寄存器刚被写入时，上面划掉的是原值、下面是新值，格子高度固定，写入不会让面板跳动；二进制模式不显示原值，右栏放不下 32 位数字时改为一排小点（实心 1、空心 0），可折成两行。文件树用画好的图标区分文件夹（展开／收起）、MIPS 源码 `.s`／`.asm`（S）、C 源码和头文件 `.c`／`.h`（C／H）、文本 `.txt` 和其他文件（空白纸张）；`.c`／`.h` 与其他 UTF-8 文本一样能打开和编辑，不参与汇编，也没有 MIPS 着色。页脚“专注模式”按钮用强调色底色。详细检查的“定位到这一行”“查找引用”“在专注模式中逐位查看”是标题行“取消固定”旁的图标。“数值显示”切换寄存器、内存、地址、行尾执行值和专注模式中的数值显示：自动（看起来像地址的值——落在代码、数据或栈的范围内——用十六进制，其余用十进制；同一个值不会因变大而换写法）、HEX、DEC、BIN、ASCII，一律带 `0x`／`0d`／`0b` 前缀或引号；单字节可打印值另以淡色注出字符（同一组位的另一种读法）。切换旁有前缀图例，“?”打开各档说明和字符编码表（ASCII），开头给出同一个数的各种写法。ASCII 档只把像字符的值读成字符，其余（例如syscall 前放进 $v0 的 11）仍以十进制显示并注明“不是可显示字符”。指令悬停优先显示中文说明；只有 MARS 英文原文的指令，会把原文里的示例寄存器和标签换成这一行实际写的，并标明“MARS 原文”。术语定义都附通用例子。重新汇编时编辑器停在当前文件。编辑器头部不再显示“已执行 N 步 · 下一条”，状态标签和底部“执行轨迹”照常显示步数。编辑器中的代码不会改变。机器指令一律显示寄存器名（`$v0` 而非 `$2`）；编辑器下方不再有“刚完成／即将执行”卡片（2026-11-03）；实际机器指令在“实际指令”视图和执行轨迹里看。寄存器的约定用途在悬停时显示。分支或跳转后的 `nop`（延迟槽占位）淡色显示，悬停说明原因。行尾灰字是这一行最近一次执行的结果：伪指令只显示整行结果（不显示汇编器临时用的 `$at`）；分支行显示比较的值和结果（如 `0d3 ≠ 0d0 成立 → 跳到 over10`）；syscall 行显示 $v0 的值选定做什么、读取的参数和动作结果。专注模式保留之前执行过的 3 行，淡色显示。

停下时，下一行（黄色）底色闪一下；如果是运行后停下、换了文件或跳过了多行，其余代码同时短暂变暗，便于一眼找到位置。减少动态效果时只保留静态高亮。

程序等待输入时，提交的内容会以蓝色回显在控制台；提交后自动继续被打断的操作（运行就接着运行，单步就完成这一步）。

逐步解释在专注模式中。点击页脚“◎ 专注”、按 Cmd/Ctrl＋K 再按 F，或在命令面板选“专注模式”进入；IDE 背景虚化，观察窗浮在上方，可拖动、调整大小。

- 左侧是刚完成的 1 步和之后的预计路径，以源码行为单位，伪指令算一行、可展开机器指令。路径按跳转切成段，段间箭头标注顺序、条件成立／不成立、跳转、调用、返回；没走的分支只给一行提示；循环回到同一段时标注第几次。范围可选“自动”（当前代码块加其去向，最多 8 行）或固定 1–8 行。预计路径由执行核心实际前瞻后恢复得到，遇到等待输入、异常或程序结束即停并说明。
- 右侧只列这几步读写到的寄存器和内存格，显示选中步骤前后的值。
- 下方是选中步骤的填空式解释：一行式子从符号形式开始，每拍代入一个真实值，当前拍的数值沿观察窗内的箭头移动；“为什么？”展开推导。系统开启“减少动态效果”时不播放动画，直接显示结论。
- 键盘：↑/↓ 只在窗口里切换查看的步骤，不执行；Shift+↑ 后退一行，Shift+↓ 执行一行（历史内为回放，到最新后执行新的一行，按住连续前进）；←/→ 上一条／下一条解释；Tab 同 ↓ 循环切换；Enter 执行到选中的这一步（含这一步）；? 看“为什么”；Esc 退出。程序等待输入时，观察窗内直接提供输入框。
- 每一条解释都有“为什么”：常见指令有专门的推导，此外一律由规则生成——操作数在指令编码中的角色（基址、源操作数、比较对象、服务编号、参数）、这个值由哪一步写入、结果之后被哪一步读取、下一条为什么是那里。没有专门推导的新指令也能得到这些说明。
- 涉及对象中，相邻的内存字节合并为一项；可显示时按文字显示，下面用小号灰字保留原始字节。
- “为什么”只陈述执行事实及其联系（值来自哪一步、结果被哪一步读取、控制台输出用到了哪个寄存器的值），不推断程序意图；意图来自源码注释，专注模式在步骤下方以“作者注释”淡色显示。界面用到的术语（伪指令、延迟槽、符号扩展、补码等）带虚线下划线，悬停看定义；定义在 `ui/glossary.js`，只讲机制，老师可编辑。
- 伪指令行默认显示整行效果（例如 `la $s0, buffer` 显示为 `$s0 = 0x1001000a`），点代码路径里的 ▸ 才逐条显示展开后的机器指令。

逐拍解释覆盖：整数加减、逻辑与 nor、比较（含立即数，区分符号扩展与零扩展）、`lui`、定长与可变移位、`mult`/`multu`/`madd`/`msub`（显示 64 位乘积与 HI/LO）、`div`/`divu`（商、余数、除零说明）、`mul`、`mfhi`/`mflo`/`mthi`/`mtlo`、`movn`/`movz`；全部条件分支给出比较结果与 `PC+4 + offset×4` 目标；`j`/`jal` 给出目标拼接，`jr`/`jalr` 指出目标寄存器，链接写入标注为返回地址。访存给出基址＋偏移，`lb`/`lh` 的符号扩展与 `lbu`/`lhu` 的零扩展，`lw`/`lh`/`sw`/`sh` 的小端序字节组合或拆分，`sb`/`sh` 的低位截取。字节序按 MARS 默认小端序。其他指令（如 `lwl`/`lwr`、浮点）仍只展示真实访问与结果。

连线默认仅显示关注对象，可在专注模式顶部的“主界面连线”切换为全部关系，实线与虚线、读取、写入、控制流可独立开关。
