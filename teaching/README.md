# MARS Trace — 教学与程序理解 IDE

MARS Trace 在原 MARS 4.5 汇编器和执行器上增加现代代码编辑、可回退调试和执行关系叠加。前端使用本地打包的 CodeMirror，不依赖 CDN。机器指令仍由原 MARS `Simulator` 执行。

## 启动

需要 JDK 17 或更新版本。已在 macOS arm64 / Java 25 验证。

在仓库根目录执行：

```sh
sh teaching/scripts/start.sh
```

打开 **http://127.0.0.1:8765**。服务只监听本机。macOS 也可以运行根目录的 `Start-Teaching-IDE.command`。终端 Ctrl+C 结束服务。

指定其他端口：`sh teaching/scripts/start.sh 8766`。首次启动会从源码编译 Java；前端已打包，正常使用无需安装 Node 依赖。当前是本地浏览器工作区，原生安装包属于 M3。

## 开始使用

1. 选择 `Hexadecimal · 位与字符`，运行到输入等待，输入 `898`，再次运行，观察 `00000382`。
2. 选择 `Task 1 · 文件与调用`，在 `task1.s` 行号旁点击设置断点；Alt＋点击可添加条件，例如 `$t0 == 0`。
3. 单步时，实线展示刚完成步骤的真实访问；虚线展示下一步预览。底部开关可分别控制两层，以及读取、写入和控制流。
4. 悬停指令或寄存器查询含义；Cmd/Ctrl＋点击或 F12 固定检查器。点击寄存器可查引用、数值表示、最后写入，以及运行到下一次写入。
5. 源码、实际指令、控制流三个视图共享位置。实际指令显示伪指令展开、机器地址和源码映射，可在展开内部设置断点。
6. 执行轨迹可按源码行折叠，也可打开循环的各次迭代。历史步骤输入框可跳转全部已保存历史；所有状态面板随之回放。

第三个 `array-sum` 示例用于验证通用性：数组读取、循环和函数调用，没有针对该示例硬编码地址或执行逻辑。

## 常用操作

| 操作 | 入口 |
| --- | --- |
| 汇编 | Cmd/Ctrl＋Enter |
| 命令面板 | Cmd/Ctrl＋K |
| 机器单步 | F7 |
| 跨过调用 | F8 |
| 运行 | F9 |
| 回退 | Alt＋Left |
| 定义／说明 | Cmd/Ctrl＋点击、F12 |
| 条件断点 | Alt＋点击断点槽 |
| 删除断点 | 再点断点槽；侧栏 Alt＋点击 |
| 读／写观察点 | WATCHPOINTS 的 ＋ |
| 运行到光标 | 命令面板 |
| 查内存 | 地址栏输入地址或标签；寄存器检查器“作为地址查看” |
| 本步相关／全部／已固定寄存器 | 寄存器筛选器 |
| 文件输入 | VIRTUAL FILES，可编辑、添加或删除后重新汇编 |

`.s` / `.asm` 文件作为源码导入；其他文本文件作为虚拟输入导入。导出工程保留源码与虚拟文件。运行配置修改后需要重新汇编。

## 时间语义

`S_n` 是完成第 n 条机器指令之后的状态。PC 指向下一条待执行指令。

- 实线：`S_(n-1) → S_n` 的真实读写和控制转移。
- 虚线：从 `S_n` 出发的下一步预览。
- 起点没有实线；终点没有可执行的下一步。
- 输入 syscall 的预览停在等待输入，即使输入队列已有内容也不提前消费。
- 预览调用同一执行核心，再恢复寄存器、内存变化、延迟分支、堆位置和虚拟 I/O，不包含第二套指令解释器。

## 开发与测试

```sh
npm ci --prefix teaching
npm run build --prefix teaching
sh teaching/scripts/test.sh
```

`test.sh` 从仓库内固定的上游 commit 导出独立基线，运行核心测试、前端语义测试、完整输出对照和逐步状态对照。

浏览器验收脚本在 `tests/browser_smoke.js`，它是接收 Playwright `page` 的异步函数表达式；启动服务后，可由 Playwright runner 加载并执行。包含编辑、输入、断点、读观察点、源码切换、叠加开关、缩放、命令筛选和历史相关检查。

架构与完成证据见 [ARCHITECTURE.md](docs/ARCHITECTURE.md) 和 [VALIDATION.md](docs/VALIDATION.md)。长期设计见 [DESIGN.md](docs/DESIGN.md)。

## Limitations

- 当前为单用户、单活动会话；多个标签页共享同一执行状态。代码修改后需要重新汇编，旧轨迹会在重新汇编时清除。
- 接受整数寄存器为主的课程工程；面板显示 GPR、HI、LO。浮点／异常寄存器被纳入回退快照，但尚无专门面板。
- 支持可回放的 syscall 1–17、34–36；时间、随机、音频、GUI 等服务明确阻止执行。文件访问使用会话内虚拟文件，不直接访问主机文件。
- 当前固定 Default 内存配置和禁止自修改代码。`.include` / `.incbin` 尚未启用，请显式导入项目源码文件。
- 条件断点支持 `$register` 与整数的 `== != < <= > >=` 比较；复杂表达式属于后续扩展。
- 调用视图按 `jal` / `jalr` / `jr $ra` 约定跟踪。循环视图按静态向后边识别；复杂非结构化控制流仍应查看实际轨迹。来源查询目前为最后写入记录，不是完整跨步依赖切片。
- 历史上限为 100,000 条机器指令，达到后明确暂停。控制台和单个虚拟输出文件有 1 MB 上限。尚未完成 M3 的长会话内存预算与发布性能验收。
- 当前固定左右工作区，支持标签页切换、信息过滤、字号和主题；任意拖拽布局、完整课程包、原生安装包与跨平台验收属于 M3。
