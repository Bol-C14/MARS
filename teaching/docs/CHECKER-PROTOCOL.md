# 语法检查进程协议

学生打字时的语法检查由一个独立的 Java 进程完成。本文写给接入网关的人。**本地测试通过不代表线上可用**：线上网关的分流、进程管理、故障重启和跨学生隔离都需要另外接入并做公网验证。

## 为什么是独立进程

MARS 汇编时会清空全局内存和符号表（`Assembler.java:194-195`），`DebugSession.assemble` 还会清掉执行历史。检查如果进入学生的调试进程，会破坏暂停中的程序。所以检查请求不得发到学生的 `Stdio` 进程。

单行检查和完整检查都走这个进程，学生调试进程完全不参与。

## 启动

```bash
java -Djava.awt.headless=true -cp teaching/build/classes mars.ide.Checker
```

- 全班共用一个进程，常驻。
- 标准输入和输出都是 UTF-8 的 JSON Lines：一行请求，一行回复。标准错误只用于日志，MARS 自己的输出也在这里。
- 严格串行：发一行，等一行，再发下一行。
- 标准输入关闭时进程退出，退出码 0。

## 请求

所有请求都有 `id`，回复原样带回。`id` 只用于对应请求，进程不解释它。

单行检查：

```json
{"protocol":1,"id":12,"command":"line","file":"main.s","text":"整个文件的文本","lines":[4,5]}
```

需要整个文件，因为判断一行时要知道文件里的 `.eqv`、宏和当前段。`lines` 是从 1 开始的行号，只检查这些行。

完整检查：

```json
{"protocol":1,"id":13,"command":"full","files":{"main.s":"…"},"entry":"main.s","delay":false}
```

`files` 只含当前汇编范围，和 `assemble` 的规则相同：路径必须是工程内相对路径，单个源码不超过 1 MB，不允许 `.include` 和 `.incbin`。不执行程序，不需要输入文件。

## 回复

```json
{"protocol":1,"id":12,"status":"ok","diagnostics":[{"file":"main.s","line":4,"column":2,"message":"\"addd\" is not a recognized operator","warning":false}],"undetermined":[]}
```

| `status` | 含义 | 前端行为 |
| --- | --- | --- |
| `ok` | 检查完成。`diagnostics` 是结果，空列表表示没有发现错误 | 显示结果 |
| `undetermined` | 这次无法判断，可能带 `reason` | 保持原样，不显示错误 |

`undetermined` 字段（行号列表）只出现在单行检查里，表示这些行要看整个程序才能判断：数据段、宏定义、指令、用到 `.eqv` 名字的行、宏调用。它们不是错误，由完整检查负责。

## 状态重置

每次完整检查都新建 `DebugSession`，汇编时清空全局内存和符号表，宏和 `.eqv` 属于每次新建的程序对象，延迟分支设置按请求设定，临时目录检查后删除。`teaching/tests/checker_test.py` 用同一进程连续检查不同程序，并逐一和全新进程的结果比较。

## HTTP 接口

```text
POST /api/check
Content-Type: application/json
```

请求和回复就是上面的 JSON。本地由 `Server.java` 转发给子进程。

前端把下面的回复当作“这个部署没有检查器”，本页不再尝试，界面不提示：404、405、501、不是 JSON、`protocol` 不是 1。其他失败（如 503）只放弃这一次。所以前端可以先于网关上线。

## 网关需要做的

1. **新增 `/api/check` 分流**，只发到检查进程，绝不进入学生的 `Stdio` 进程，也不要求学生已有会话。
2. **校验请求**：大小上限 8 MB，`command` 只允许 `line` 和 `full`，并沿用现有的来源和会话校验。
3. **公平排队**：全班共用一个串行队列。同一学生只保留最新的未执行任务，旧任务直接替换。回复后先核对 `id`，不要串给别的学生。
4. **单独处理超时**：单次检查限时 5 秒。超时后强制结束检查进程并重启，这次回复 `status: "undetermined"`。**不能走现有的执行超时路径**，那条路径会销毁学生会话和调试进度。检查失败绝不能影响任何学生的调试进程。
5. **进程退出时重启**：标准输出读到 EOF 就重启，当前请求回复 `undetermined`。
6. **排队已满时**回复 503 或 `undetermined`，不要阻塞 `/api`。

## 线上验收

- 学生停在断点上，记录寄存器、内存、PC 和执行历史，多次触发完整检查后完全不变。
- 两个学生同时检查不同程序，结果互不串扰，一方的标签不影响另一方。
- 让检查进程卡住：只有这次检查得到 `undetermined`，所有学生的调试会话都在。
- 杀掉检查进程：能自动恢复，学生没有感知。
- `.eqv` 和宏不误报。
