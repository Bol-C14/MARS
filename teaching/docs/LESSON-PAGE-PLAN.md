# MARS Trace 教学页面规划

目标：帮助学习 MIPS 和计算机组成的学生解决具体问题，并让教师能直接分享一段可操作的课堂材料。页面先以英文为主，逐步补充中文；本文件是选题规划，尚未创建教学页面。

## 第一批候选题目

1. **MIPS 分支与循环调试**：从一个容易出错的循环开始，先预测分支，再在 IDE 中单步观察、回退并修正。候选搜索表达：`debug MIPS loop`、`MIPS branch instruction example`。
2. **MARS syscall 和文件输入输出**：解释服务号、参数和返回值；用可运行的小例子展示终端输入输出以及 `input.txt` / `output.txt`。候选表达：`MIPS syscall examples`、`MARS read file syscall`。
3. **寄存器、内存和栈**：通过 `lw` / `sw` 和函数调用观察地址、栈指针与栈帧。候选表达：`MIPS stack frame example`、`MIPS load store explained`。
4. **有符号溢出与补码**：预测加法或减法结果，再使用单步和寄存器观察排查溢出。候选表达：`MIPS signed overflow example`、`MIPS two's complement`。

这些搜索表达是待验证的想法，不代表已验证搜索量或竞争程度。优先选一篇依据课堂实际反馈制作，并通过 Search Console 和使用反馈调整。

## 每页结构

- 一个具体问题和学习目标，附预期时间与需要的基础。
- 一段简短代码，让学生先预测结果。
- 可打开相应示例的 IDE 链接，保留现有工程保护和恢复机制。
- 按步骤观察寄存器、内存、分支或输出，解释容易产生的误解。
- 一个变化练习和教师可用的提示，最后邀请反馈。

每篇要有独立、能直接阅读的文字说明；中英文分别使用稳定网址并相互链接。内容和例子应经过运行验证，代码、图片和叙述保持一致。

## 观察效果

先关注页面收录和自然搜索展示，再看页面到 IDE 的访问、汇编、单步与反馈。现有活动筛选在跨页面时不一定关联 IDE 事件，因此先核实统计链路，再计算转化；不收集学生源代码。
