# 程序生成的文件

syscall 13（写入或追加）和 15 操作的是当前调试会话的虚拟文件。生成文件按路径显示在原文件树中，并标为“输出”；点击可只读预览，通过下载按钮保存原始字节。

源码和工程输入不被运行结果覆盖。同名输入可在输出预览里选择“查看工程中的原始输入”。重新汇编会创建新的运行文件系统；输出目前不写入浏览器工程草稿或工程 ZIP，重要结果请单独下载。

`state.generatedFiles` 是路径到 `{base64, size}` 的映射。打开写入模式就记录空文件，写入后更新；回退和预览使用 VirtualIO 快照，不污染真实执行。此数据只供显示、下载，不自动成为下次汇编的输入。

验证：核心用例检查写入及回退的字节；`python3 teaching/tests/output_browser.py <地址>` 检查嵌套目录、同名输入保留、预览和下载。
